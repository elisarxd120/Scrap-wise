Kitchen Staff User Guide

Warning: one or more kitchen items are at or below the reorder level.

Dashboard

Review today’s waste, bin capacity, low-stock items, processing status, and recent alerts. Use the quick-action buttons to open common tasks.

Stock In / Out

  1. Select Stock In or Stock Out.
  2. Choose an inventory item from the item list.
  3. Enter a quantity greater than zero.
  4. For Stock Out, select a reason.
  5. Save the movement. Inventory quantities are updated automatically.

Only movements created by you today can be updated.

Inventory

Search inventory, filter by category, or show low-stock items only. Green items are in stock, orange items are low, and red items are out of stock. Use Stock In to open the stock form for a selected item.

Waste Loading

  1. Select the waste device used.
  2. Enter the measured weight in kilograms.
  3. Confirm the loading date and time.
  4. Save the waste loading record.

Processing Status

  1. Select the processing date.
  2. Choose Recorded, Processing, or Processed for each reading.
  3. Enter before and after weights when available.
  4. Select Update to save the row.

Alerts

Use the unread filter to view only new alerts. Mark an individual alert or all alerts as read. The navigation badge is updated automatically.
